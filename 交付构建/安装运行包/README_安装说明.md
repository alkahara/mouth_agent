# 口腔智能体安装运行说明

## 运行环境

- Windows 10/11
- Conda 环境：`weixinkouqiang`，Python 3.11
- MySQL：本机 `3306` 端口，数据库名 `assistant_auth`
- 微信开发者工具

## 首次安装

1. 双击 `01_安装依赖.bat`。
2. 将 `配置模板/agent.env.example` 复制为 `后端/Agent/.env`，填写百炼 API Key。
3. 将 `配置模板/gateway.env.example` 复制为 `后端/身份网关/.env`，填写 MySQL 密码和随机 JWT 密钥。
4. 双击 `02_初始化数据库.bat`。
5. 双击 `03_启动服务.bat`。
6. 双击 `04_打开小程序.bat`，或在微信开发者工具中导入 `小程序` 文件夹。

## 本地地址

- Agent：`http://127.0.0.1:8000`
- 身份网关：`http://127.0.0.1:8001`
- 小程序开发配置默认连接身份网关 `8001` 端口。

## 停止服务

双击 `05_停止服务.bat`。脚本仅停止监听 `8000` 和 `8001` 端口的进程。

## 注意事项

- 本包未包含 API Key、数据库密码等私密配置。
- 本地模拟器需在微信开发者工具中关闭“不校验合法域名”。
- 真机调试需要 HTTPS 地址，并在微信公众平台配置 request 合法域名。
- Agent 使用进程内对话状态，服务重启后会话状态清空。
