  口腔术后出血处理流程总结

  一、风险分级体系（图例）

  - 无风险（绿色）→ 日常维护
  - 低风险（青色）→ 观察避免发烧
  - 中风险（橙色）→ 立即寻求医疗服务
  - 高风险（红色）→ 拨打120/就近急诊科治疗

  二、主流程分支

  入口：患者询问种植术后出血相关问题
  - 需要人文关怀
  - 询问患者出血诱因
  - 询问患者手术时间

  分支A：术后5天内

  初步评估：
  - 询问患者上次做了什么手术
  - 了解可能解决血管穿刺继发的术式（如下牙槽血管缝合、上颌窦上关键动脉分支、鼻底软组织等）

  按出血部位分类：

  1. 舌侧出血
    - 询问出血表现 → 辅助患者判断出血程度
    - 伤口轻微渗血 → 需要人文关怀 → 指导压迫止血
        - 未压正常吸象 → 无风险 → 日常维护
      - 压迫血血后不再出血 → 需要人文关怀 → 低风险 → 观察避免发烧
      - 压迫止血后再次出血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
    - 伤口活动性出血 → 指导压迫止血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
  2. 腭侧出血
    - 询问出血表现 → 辅助患者判断出血程度
    - 可压迫止血 → 需要人文关怀 → 指导压迫止血
        - 未压正常吸象 → 无风险 → 日常维护
      - 压迫止血后不再出血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
      - 压迫止血后再次出血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
    - 无法压迫止血 → 需要人文关怀 → 短时间出血量过度/部位特殊 → 需要人文关怀 →
  指导紧急处理措施
        - 压迫止血后再次出血 → 需要人文关怀 → 高风险 → 拨打120/就近急诊科治疗

  分支B：术后>5天

  症状评估：
  - 伴有伤口疼痛、裂开、或会并发鼻炎

  按出血部位分类：

  1. 舌侧出血
    - 询问缘由：唾液、过渡义齿等损伤口
    - 需要人文关怀 → 指导压迫止血
        - 压迫止血后不再出血 → 需要人文关怀 → 低风险 → 观察避免发烧
      - 压迫止血后再次出血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
  2. 腭侧出血
    - 询问缘由：唾液、过渡义齿等损伤口
    - 需要人文关怀 → 指导压迫止血
        - 压迫止血后不再出血 → 需要人文关怀 → 中风险 → 立即寻求医疗服务
      - 压迫止血后再次出血 → 中风险 → 立即寻求医疗服务

  三、核心处理原则

  1. 时间节点：以术后5天为分界点
  2. 部位区分：舌侧和腭侧处理策略不同
  3. 人文关怀：流程中多次强调需要人文关怀
  4. 压迫止血：核心处理手段是指导患者压迫止血
  5. 动态评估：根据压迫止血效果判断风险级别
  6. 分级处理：根据风险级别给予相应的处理建议

  四、关键决策点

  - 出血时间（5天内 vs >5天）
  - 出血部位（舌侧 vs 腭侧）
  - 出血性质（轻微渗血 vs 活动性出血）
  - 压迫止血效果（止血 vs 再次出血）
  - 特殊情况（无法压迫止血、出血量过度）
