## 目标
外部视频（优酷等）不再跳转到独立的 video 页面，而是在当前页面用浮层播放器（`<web-view>` 覆盖层）观看，关闭即回到对话。直接视频（mp4/m3u8）已内嵌 `<video>`，保持不变。

## 实现步骤

### 1. `pages/index/index.js`
- 新增 data 字段 `videoPlayer: { visible: false, url: '' }`。
- 新增方法 `openInlineVideo(event)`：从 dataset 取 url，复用 video.js 里的优酷转换逻辑（`/id_(XXX)/` → `https://player.youku.com/embed/XXX`），设置 `videoPlayer.visible = true` 和转换后的 url。
- 新增方法 `closeInlineVideo()`：设置 `videoPlayer.visible = false` 并清空 url。
- 删除旧的 `openVideo`（跳转 navigateTo 逻辑）。

### 2. `pages/index/index.wxml`
- 视频卡片里「打开视频」按钮的 `bindtap` 从 `openVideo` 改为 `openInlineVideo`（不再跳转）。
- 在 `page-shell` 之外、`dialog-mask` 附近，新增浮层播放器区块：
  ```
  <view class="video-player-mask" wx:if="{{videoPlayer.visible}}" catchtouchmove="stopPropagation">
    <view class="video-player-bar">
      <view class="video-player-close" bindtap="closeInlineVideo">关闭</view>
    </view>
    <web-view wx:if="{{videoPlayer.url}}" src="{{videoPlayer.url}}"></web-view>
  </view>
  ```

### 3. `pages/index/index.wxss`
- 新增 `.video-player-mask`：`position: fixed; inset: 0; z-index: 1100`（高于 dialog-mask 的 1000），半透明黑色背景，flex 居中。
- `.video-player-bar` / `.video-player-close`：浮层顶部一个简洁的关闭按钮条。

### 4. 不改动 `pages/video/` 
- 保留 video 页面（app.json 仍注册），避免影响其它入口；只是首页不再调用它。

## 影响范围
- 仅 `pages/index/index.js`、`index.wxml`、`index.wxss` 三个文件。
- 行为变化：点「打开视频」→ 当前页弹出 web-view 浮层播放，点「关闭」回到对话，无页面跳转。
